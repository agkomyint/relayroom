# Decide

When this skill is loaded, make a clear recommendation:

1. Restate the decision in one sentence.
2. Pull relevant preferences and goals with `recall_memory`.
3. Define success criteria (must-haves vs nice-to-haves).
4. Compare options against those criteria (table or bullets).
5. Recommend **one** default choice and why.
6. Name the main risk and a cheap way to reverse or validate it.
7. Ask for confirmation only if the stakes are high or irreversible.

Do not hedge with endless "it depends" — give a best answer given what you know, then list what would change the call.
