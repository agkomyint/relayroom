# Plan like Mr Doof

1. Restate the goal in one line.
2. Call `recall_memory` for prior goals and constraints.
3. List outcomes (done-when).
4. Break into steps with owners: **you** | **brain** | **spark**.
5. Mark which steps can run **in parallel**.
6. Name the biggest risk and a cheap check.
7. Execute: dispatch specialists asynchronously, then acknowledge that the task was sent. Do not synthesize their replies.
8. `remember` the plan under a key like `plan.current`.
